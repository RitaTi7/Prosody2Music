###########  WORD BEGINNING SEARCH

There are 2 files you have to use: CHILD_prepbeg_nOfLet.R and CHILD_beg.R

The two files work exactly in the same way as those for adults. For a detailed description on how to use the functions, please, refer to the README_ForRUsers.txt file (section WORD BEGINNING SEARCH).


###########  WORD ENDING SEARCH

There is only one function: CHILD_finSeq.R; this function works exactly as the function finSeq.R for the adult database. For a detailed description on how to use the functions, please, refer to the README_ForRUsers.txt file (section WORD ENDING SEARCH, point 2)).
